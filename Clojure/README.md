# Встраиваемый DSL для управления состоянием клиента мессенджера

Этот проект демонстрирует разработку **встраиваемого языка специфического домена (DSL)**, построенного на основе **Clojure**, диалекта языка Lisp. DSL предназначен для управления состоянием клиентского приложения мессенджера, предоставляя ясный и выразительный способ определения, обновления и реакции на изменения состояния в ответ на события.

## Возможности DSL

Встраиваемый DSL предоставляет следующие основные функции:

*   `defstate`: Определяет начальную структуру и значения состояния клиента.
*   `on-event`: Определяет, как состояние должно обновляться в ответ на определённый тип события, включая логику обработки данных события.
*   `trigger-event`: Функция для симуляции или вызова события, которое затем запускает соответствующий обработчик и обновляет состояние.

## Как это работает

1.  **Определение состояния:** Состояние приложения определяется с помощью макроса `defstate`, обычно в виде Clojure-карты (map), содержащей ключи, такие как `:chats`, `:current-chat-id`, `:user` и т.д.
2.  **Обработка событий:** Разработчики определяют обработчики событий с помощью макроса `on-event`. Этот макрос принимает тип события (например, `:new-message`) и тело функции, которое указывает, как карта состояния должна быть преобразована при наступлении этого события. Внутри используются неизменяемые структуры данных Clojure и функции функционального обновления, такие как `assoc`, `update-in`.
3.  **Макросы:** Макросы `defstate` и `on-event` реализованы с использованием мощной системы макросов Clojure. Это позволяет им генерировать базовый Clojure-код, необходимый для хранения состояния (с использованием `atom`) и логики обработки событий во время компиляции, обеспечивая чистый и настраиваемый синтаксис.
4.  **Обновление состояния:** Когда вызывается `trigger-event`, он ищет зарегистрированный обработчик для заданного типа события, выполняет его с текущим состоянием и данными события, и использует `swap!`, чтобы атомарно обновить глобальный атом состояния.

## Установка и использование

1.  **Предварительные требования:**
    *   Среда выполнения Java (JRE) версии 8 или выше.
    *   Инструмент сборки [Leiningen](https://leiningen.org/) для Clojure.
2.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com/DmitriiKolotuhin/DSL.git
    cd YOUR_REPOSITORY_NAME
    ```
3.  **Запуск демонстрации:**
    Выполните основную функцию с помощью Leiningen:
    ```bash
    lein run
    ```
    Это запустит демонстрационный код, находящийся в `src/my_messenger_dsl/core.clj`.

## Пример

Файл `core.clj` включает в себя демонстрацию работы DSL:

1.  Определяет начальное `client-state` с чатами и информацией о пользователе.
2.  Регистрирует обработчики для событий `:new-message`, `:switch-chat` и `:update-user-status`.
3.  Вызывает эти события по очереди.
4.  Выводит состояние до и после каждого события, чтобы показать изменения.

Запуск `lein run` выведет результат, аналогичный логу, зафиксированному в проекте.
